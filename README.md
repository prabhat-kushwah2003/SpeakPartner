# Speak Partner

Speak Partner is a real-time communication platform developed using the MERN Stack and Socket.IO. The platform is designed to help users improve their English speaking skills by connecting with random users through live video calls and real-time interaction.

The application provides secure authentication, live online user tracking, profile customization, and seamless communication to create an interactive environment for practicing spoken English with people around the world.

## Installation and Setup

### Clone the Repository

```bash
git clone https://github.com/prabhat-kushwah2003/SpeakPartner.git
```

---

### Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:3000
```

Start the backend server:

```bash
npm start
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
